Lab: Data Visualization Using Kaggle and Tableau

Lab Topic: Data Analytics and Visualization
Difficulty: Beginner
Estimated Time: 2–3 Hours
Total Points: 100
Required Software: Tableau Public
Data Source: Kaggle

1. Lab Overview

Data visualization is an essential component of data analytics. Organizations collect large amounts of information, but raw data can be difficult to interpret without appropriate tools.

Tableau is a business intelligence and data visualization platform that enables users to transform datasets into charts, graphs, maps, and interactive dashboards.

Kaggle is an online data science community that provides access to thousands of datasets covering business, healthcare, technology, sports, finance, and many other subjects.

In this lab, students will obtain a dataset from Kaggle, import it into Tableau, examine its structure, and develop visualizations that communicate meaningful findings.

2. Learning Objectives

Upon completing this lab, students will be able to:

  1. Explain the purpose of data visualization.
  2. Locate and download datasets from Kaggle.
  3. Identify CSV files and understand their structure.
  4. Import external data into Tableau.
  5. Distinguish between dimensions and measures.
  6. Identify and correct common data quality issues.
  7. Create bar charts, line charts, and scatter plots.
  8. Develop an interactive Tableau dashboard.
  9. Interpret visualized data and communicate findings.

3. Background Information

What Is Kaggle?

Kaggle is an online platform that hosts publicly available datasets and provides tools for data analysis and machine learning. Researchers, organizations, and individuals contribute datasets that can be used for educational and analytical purposes.

Website: https://www.kaggle.com/datasets

What Is Tableau?

Tableau is a visual analytics application that allows users to explore datasets without writing extensive programming code. Its drag-and-drop interface supports charts, dashboards, filters, and interactive exploration.

Tableau Public is a free platform for creating and sharing visualizations publicly.

Website: https://public.tableau.com/

Important: Tableau Public publishes shared workbooks publicly. Do not upload confidential, private, or personally identifiable information. Use an appropriately licensed public dataset.

Important Terminology

TermDefinition
Dataset A structured collection of information.
CSV Comma-Separated Values, a common text-based data format.
Dimension A field used to categorize data, such as product or region.
Measure A numeric field used for calculations, such as sales or profit.
Worksheet A Tableau workspace containing an individual visualization.
Dashboard A collection of related visualizations presented together.
Filter A control that limits the data displayed.
Aggregation A calculation combining multiple records, such as SUM or AVG.

4. Part One: Install Tableau Public

Step 1: Open Tableau Public

  1. Open a web browser.
  2. Navigate to Tableau Public.
  3. Create a free Tableau Public account if necessary.
  4. Locate the option to download Tableau Public Desktop.
  5. Download the installer for Windows or macOS.

Step 2: Install the Application

  1. Locate the downloaded installation file.
  2. Run the installer.
  3. Follow the installation prompts.
  4. Launch Tableau Public.
  5. Sign in when prompted.
Checkpoint: You should now see the Tableau Public start screen, including options for connecting to data.

5. Part Two: Download a Dataset from Kaggle

Step 3: Create a Kaggle Account

  1. Visit Kaggle.com.
  2. Select Register or Sign In.
  3. Create an account using an available registration method.
  4. Navigate to the Datasets section.

Step 4: Find a Dataset

For this exercise, we will use a retail sales dataset.

  1. Navigate to Kaggle Datasets.
  2. Search for Sample Superstore Sales.
  3. Select a dataset containing retail sales transactions.
  4. Review its description, columns, file format, and license.
  5. Choose a dataset that includes the following fields:
  • Order Date
  • Region
  • Category
  • Sales
  • Profit

A dataset containing Sub-Category and Discount is especially useful.

Search Kaggle for Superstore datasets

Dataset note: Kaggle datasets are contributed by different authors. Column names and available files may differ. For consistent results, choose a Superstore dataset containing the fields listed above. If necessary, use the closest equivalent column names.

Step 5: Download and Extract the Data

  1. Click the Download option on the selected dataset.
  2. Save the ZIP or CSV file to your computer.
  3. If downloaded as a ZIP, extract its contents.
  4. Locate the CSV file.
  5. Open the CSV using Excel or a text editor.
  6. Review the column headings and several records.

Example dataset structure:

Order Date Region Category Sales Profit
2023-01-05 East Furniture 250 35
2023-01-06 West Technology 780 125
2023-01-07 Central Office Supplies 95 18

These records are illustrative, not actual Kaggle results.

6. Part Three: Import Data into Tableau

Step 6: Connect to the CSV File

  1. Open Tableau Public Desktop.
  2. Locate the Connect section.
  3. Select Text File.
  4. Browse to the downloaded CSV file.
  5. Select the file and click Open.
  6. Wait for Tableau to load the dataset.

Tableau should display a preview of the dataset on the Data Source page.

Step 7: Examine the Dataset

Review the following information:

  • Number of columns
  • Available field names
  • Data types
  • Missing values
  • Numerical versus categorical information

Common Tableau data types include:

  • Abc – Text/String
  • # – Numeric values
  • Calendar icon – Date values
  • Globe icon – Geographic values

Verify that Sales and Profit are numeric fields and Order Date is a date field.

7. Part Four: Data Cleaning

Step 8: Check Data Types

  1. Locate the Sales field.
  2. Confirm it has a numeric data type.
  3. If necessary, select the field's data type icon.
  4. Change it to Number (Decimal).
  5. Repeat for Profit.
  6. Locate Order Date.
  7. Ensure it is assigned the Date data type.

Step 9: Identify Missing Values

  1. Open a new worksheet.
  2. Drag Region to Rows.
  3. Drag Number of Records to Text, if available.
  4. Alternatively, use COUNT of a populated identifier.
  5. Look for Null or blank Region values.
  6. Inspect other important fields for missing values.

Document any data quality issues discovered.

Important: Do not automatically replace missing sales or profit values with zero. A missing value is not necessarily a zero. Explain any cleaning decisions in your lab report.

8. Part Five: Create Visualization #1

Bar Chart: Total Sales by Region

Step 10: Create a New Worksheet

  1. Click Sheet 1 or create a new worksheet.
  2. Rename the worksheet Sales by Region.
  3. Locate Region in the Data pane.
  4. Drag Region to the Rows shelf.
  5. Locate Sales.
  6. Drag Sales to the Columns shelf.
  7. Confirm the aggregation is SUM(Sales).
  8. In the Marks card, select Bar if necessary.

Step 11: Format the Bar Chart

  1. Click the Sort Descending button to rank regions.
  2. Drag SUM(Sales) to Label on the Marks card.
  3. Enable Show Mark Labels if necessary.
  4. Format Sales as currency.
  5. Change the title to Total Sales by Region.
  6. Optionally drag Region to Color.

Your completed visualization should display regional sales totals as horizontal bars.

Questions

  1. Which region has the highest sales?
  2. Which region has the lowest sales?
  3. What is the difference between these regions?
  4. What business decisions could this information support?

9. Part Six: Create Visualization #2

Line Chart: Sales Over Time

Step 12: Build a Time-Series Visualization

  1. Create a new worksheet.
  2. Rename it Monthly Sales Trend.
  3. Drag Order Date to Columns.
  4. Use the date pill menu to select Month as a continuous date value, preserving year information.
  5. Drag Sales to Rows.
  6. Confirm the measure is SUM(Sales).
  7. Change the Marks type to Line.
  8. Set the worksheet title to Monthly Sales Trend.

This visualization will illustrate how sales change over time.

Step 13: Analyze the Sales Trend

  1. Identify periods of increasing sales.
  2. Identify periods of decreasing sales.
  3. Look for unusually high or low values.
  4. Determine whether seasonal patterns are visible.
  5. Record at least two observations.
Tip: A discrete Month date part can combine the same month across multiple years. Use a continuous month-level date to show a chronological timeline.

10. Part Seven: Create Visualization #3

Scatter Plot: Sales Versus Profit

Step 14: Create a Scatter Plot

  1. Create a new worksheet.
  2. Rename it Sales vs Profit.
  3. Drag Sales to Columns.
  4. Drag Profit to Rows.
  5. Confirm SUM(Sales) and SUM(Profit) are used.
  6. Change the Marks type to Circle.
  7. Drag Sub-Category to Detail on the Marks card.
  8. If Sub-Category is unavailable, use another appropriate categorical field.
  9. Drag Category to Color if available.
  10. Set the title to Sales vs Profit.

Adding a categorical field to Detail creates separate marks rather than displaying only one aggregated point.

Step 15: Interpret the Scatter Plot

Answer the following questions:

  1. Do higher sales always correspond to higher profits?
  2. Which categories have negative profits?
  3. Are there any outliers?
  4. What might explain low-profit, high-sales products?

Consider how discounts, expenses, or pricing might influence profitability.

11. Part Eight: Create an Interactive Dashboard

Step 16: Create the Dashboard

  1. Click the New Dashboard icon.
  2. Rename the dashboard Superstore Sales Dashboard.
  3. Choose a suitable dashboard size.
  4. Drag Sales by Region onto the dashboard.
  5. Drag Monthly Sales Trend onto the dashboard.
  6. Drag Sales vs Profit onto the dashboard.
  7. Arrange the charts so they are easy to read.
  8. Ensure titles and labels are visible.

Step 17: Add Interactive Filtering

  1. Return to the Sales by Region worksheet.
  2. Drag Region to the Filters shelf.
  3. Select all regions and confirm.
  4. Right-click the Region filter and select Show Filter.
  5. Return to the dashboard.
  6. Locate the Region filter control.
  7. Use the filter menu and choose Apply to Worksheets, then All Using This Data Source.
  8. Test the filter by selecting different regions.

All three visualizations should update when a different region is selected, provided they use the same compatible data source.

Step 18: Improve Dashboard Appearance

  1. Add a descriptive dashboard title.
  2. Use consistent colors.
  3. Ensure labels are readable.
  4. Remove unnecessary visual clutter.
  5. Adjust chart sizes.
  6. Test all filters and tooltips.

12. Part Nine: Save and Publish

Step 19: Save Your Workbook

  1. Open the File menu.
  2. Select the available save or publish option.
  3. Sign in to Tableau Public if prompted.
  4. Use a descriptive workbook title.
  5. Publish your visualization to Tableau Public.
  6. Open the published dashboard in your browser.
  7. Copy its public URL.
Privacy reminder: Tableau Public is intended for publicly shareable data. Review the dataset and workbook before publishing.

16. Troubleshooting Guide

Problem Possible Solution
CSV file will not open Confirm the ZIP file was extracted and select the CSV file.
Sales appears as text Change the data type to Number (Decimal).
Dates are not recognized Verify the date format and select the correct date data type.
Only one point appears in the scatter plot Add a categorical dimension to Detail.
Charts display unexpected totals Review the aggregation and check for duplicated records.
Dashboard filter does not update all charts Verify the filter applies to all relevant worksheets.
Tableau Public will not publish Check your internet connection and Tableau Public sign-in.

18. Optional Challenge: Advanced Analytics

Students seeking additional experience may complete one or more of the following activities.

  • Create a calculated field for Profit Margin.
  • Add a geographic map showing sales by state.
  • Create a Top 10 Products visualization.
  • Add Category and Sub-Category filters.
  • Use a trend line to examine relationships.

Example Calculated Field: Profit Margin

In Tableau, select Analysis > Create Calculated Field and enter the following formula: 


IF SUM([Sales]) != 0 THEN
    SUM([Profit]) / SUM([Sales])
END

Name the field Profit Margin and format it as a percentage.

19. Conclusion

This lab introduced students to a practical data analytics workflow using Kaggle and Tableau.

Students learned how to locate a public dataset, download and import data, validate field types, create multiple visualizations, and combine those visualizations into an interactive dashboard.

These skills are relevant to business intelligence, data analytics, cybersecurity reporting, financial analysis, and software development.

The ability to transform raw data into meaningful visual information is a valuable skill across many technical and business professions.
